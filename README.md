## 🔨 What I've Been Building & Exploring

- 🧠 **Deterministic AI & RAG**: Built [`callmemaybe`](https://github.com/MohsineDas04), a constrained decoding engine in Python that uses Finite State Machines and logit masking to guarantee structured JSON from LLMs, alongside local RAG pipelines for querying codebases.
- ⚙️ **Concurrency & Algorithms**: Engineered deadlock-free thread schedulers in C (`Codexion`), multi-agent time-space Dijkstra pathfinders (`Fly-In`), and algorithmic maze engines (`a_maze_ing`).
- 🌐 **Full-Stack Products**: From AI-powered debate platforms (`ProveIt`) and interactive mystery games (`InterroGate`) to co-founding peer-to-peer marketplace architectures (`Marvo`).
- 🛠️ **How I Work**: Learn by building, break the problem down to first principles, and don't rely on magic abstractions until you understand what they're hiding.
